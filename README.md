# 90 Days of Engineering

**September 12 → December 12, 2026**

A 90-day challenge to become a stronger **Software Engineer**, with a secondary focus on **AI Software Engineering**.

The goal is not to learn every technology.

The goal is to develop stronger engineering fundamentals, solve problems better, build production-quality software, and become more confident designing and deploying real systems.
